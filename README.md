# 🏦 HackerMoney | Advanced Bug Bounty Banking (Simulation)

HackerMoney ek sleek, high-fidelity, aur mobile-responsive web-based simulation platform hai jise Bug Bounty Payouts aur modern fintech banking interfaces ko demonstrate karne ke liye banaya gaya hai. 

Yeh project puri tarah se **HTML5, CSS3 (Variables & Animations), aur Vanilla JavaScript** par chalta hai, jo ise lightweight aur bina kisi server dependency ke chalne ke kabil banata hai.

---

## 🚀 Purpose & Educational Use

Yeh platform Cybersecurity instructors, Ethical Hacking students, aur Frontend developers ke liye ek behtareen learning tool hai. Iska upyog niche di gayi cheezon ko sikhane ke liye kiya ja sakta hai:
- **State Management:** JavaScript ke jariye bina backend ke real-time balance aur transaction history update karna.
- **UI/UX Design:** Dark-cyberpunk theme, smooth CSS transitions, aur mobile-first responsive architecture.
- **Application Logic Testing:** Front-end validations aur simulation workflows (jaise QR scan aur payments).

---

## ✨ Key Features

- **🔒 Mock Authentication:** Ek functional login system (`raj` / `raj00`) ke sath secure-looking interface simulation.
- **💰 Live Balance & History:** Dynamic layout jo transactions (Credits/Debits) ko maintain aur show karta hai.
- **📋 Filter & Search:** Real-time transaction filtering (All, Credits, Debits) aur search-by-title feature.
- **💸 Send Money Workflow:** Ek dummy payment interface jahan user UPI ID daal kar balance deduct kar sakta hai.
- **📷 QR Scanner Simulation:** Interactive QR scanner module jo actual camera permissions ke bina ek scan process ko simulate karta hai.
- **📱 Premium Mobile UI:** Fully optimized phone-frame container jisme sleek glassmorphism aur pulse animations ka use kiya gaya hai.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Properties, Flexbox, Grid, Keyframe Animations)
- **Scripting:** JavaScript (ES6, In-memory State Management, DOM Manipulation)
- **Icons/Fonts:** System UI Fonts, native emojis for light-weight loading.
